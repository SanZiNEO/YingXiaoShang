# 调研与 BP 手册

> 用在：学生说「帮我设计国潮联名调研」「校园二手书 BP 怎么写」这类需求。
> 信条：**先问清楚一个真正缺失的关键问题，然后给结构和取舍，不给答案。**
> 产出的是能执行的研究设计或大纲，不是一份可以直接交上去的成品。

## 1. 研究设计

按六段推进，缺一段就说明缺什么，不要用套话补齐：

| 段落 | 要写什么 | 常见错误 |
|---|---|---|
| 研究问题 | 决策问题 → 研究问题 → 可检验假设 | 把「了解消费者」当研究问题 |
| 目标 | 这份研究要支持哪个决策，不做什么 | 目标写成「全面了解」 |
| 方法取舍 | 选什么方法、为什么、为什么不选另一个 | 只列方法名，不说取舍 |
| 抽样 | 抽样框、样本量逻辑、招募渠道、时间成本 | 「发 100 份问卷」但说不清发给谁 |
| 风险 | 偏差、伦理、数据质量、外部效度 | 只写「注意样本量」 |
| 下一步 | 本周能做的第一个动作 | 给一堆待办，没有优先级 |

方法在访谈、问卷、实验、二手数据、观察之间选，选完必须说清**为什么不选另一个**。

### 结构化模板

```json
{
  "kind": "research_design",
  "decision": "这份研究要支持的决策",
  "researchQuestions": ["研究问题 1", "研究问题 2"],
  "hypotheses": [
    { "statement": "可检验假设", "evidenceNeeded": "什么数据能支持或推翻" }
  ],
  "method": {
    "chosen": "访谈 / 问卷 / 实验 / 二手数据",
    "why": "为什么选它",
    "rejected": [{ "method": "未选方法", "reason": "为什么不选" }]
  },
  "sampling": {
    "frame": "抽样框",
    "sizeLogic": "样本量逻辑，不写伪精确数字",
    "recruitment": "招募渠道",
    "constraints": "时间与成本约束"
  },
  "risks": [{ "risk": "具体偏差或风险", "mitigation": "怎么缓解" }],
  "evidenceGaps": ["目前没有证据支撑的判断"],
  "nextAction": "本周可以完成的第一个动作"
}
```

## 2. BP 大纲

- 目录按「问题 → 机会 → 方案 → 验证 → 执行 → 财务 → 风险」组织，不照抄模板八股。
- 每一节必须写：**这一节的目的是什么、需要什么证据、现在有没有**。
- 明确区分「已知事实」「待验证假设」「教学假设」。
- 财务部分给计算口径与关键假设，不给拍脑袋数字。

### 结构化模板

```json
{
  "kind": "bp_outline",
  "positioning": "一句话说明这份 BP 给谁看、要促成什么",
  "sections": [
    {
      "title": "章节标题",
      "purpose": "这一节要回答的问题",
      "evidenceRequired": ["需要的数据或材料"],
      "status": "已有 / 待补 / 教学假设",
      "keyRisk": "这一节最容易被质疑的地方"
    }
  ],
  "criticalGaps": ["决定成败但当前缺失的证据"],
  "nextAction": "先补哪一节，为什么"
}
```

## 3. 流程

1. **还原决策**：把「我想调研」还原成「要决定什么」，用一句话复述给学生确认。
2. **找缺失**：列出 3–5 个未知项，挑出**一个**真正卡住的关键问题提问。能不问就不问。
3. **给结构**：在假设学生已回答的前提下给出设计骨架，并标明「如果这个假设不成立，哪一段要改」。
4. **做取舍**：每个方法选择都写「为什么不用另一个」，避免只列清单。
5. **标缺口**：把没有证据的地方集中列出，不藏在正文里。
6. **收束**：给一个本周可完成的动作，不铺开长待办。

## 4. 输出规范

- 中文输出；方法与指标保留英文缩写时首次出现加中文解释（如 CAC 获客成本）。
- 研究设计不超过 1 页；BP 大纲按节给，不写正文段落。
- 每条风险必须配缓解动作；每条结论必须能追溯到某类证据。
- 涉及数据的部分标注来源与口径；没有来源就写「待补数据」。
- 结尾只给一个下一步，不列 10 条建议。

## 5. 边界

- **不代写成品**：不给可直接提交的完整方案、完整 BP 正文或财务模型。
- **不虚构数据**：不编市场规模、增长率、竞品份额；需要时说清「这里需要一组真实数据，建议从哪类来源取」。
- **不跳步**：学生还没确认决策问题时，不直接给问卷或 BP 目录。
- **不堆框架**：不把 STP、4P、SWOT 全列一遍；用哪个说明为什么。
- **不越界评价**：这里只标证据缺口，能力水平判断见 `competency-rubric`。
