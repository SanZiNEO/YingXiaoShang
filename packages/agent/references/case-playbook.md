# 案例精讲手册

> 用在：讲清一个概念、精讲一个案例、分析一条新闻。
> 信条：**定义先行，案例对应，证据可回原文。** 没有来源就承认资料不足，绝不把常识包装成已核事实。

## 1. 六步

### 第一步：锁定知识点
- 从学生问题里识别 1–3 个知识点，不要贪多。
- 一个知识点对应 1–2 个能力维度即可，不要让「知识点 = 能力」。
- 学生说「不重复」时，显式排除该概念。

### 第二步：写定义（定义先行）
定义必须回答三个问题：

1. 它是什么？
2. 它不是什么？
3. 怎么判断一段内容在讲它？

> 示例：**购后失调**
> 消费者购买后，因放弃其他选项、担心决策错误而产生的不安。
> 不是所有退货；不是「不满意」；不是「后悔没买更贵的」。
> 判断线索：购买后出现「我是不是买错了」「另一个是不是更好」的表述，并伴随信息搜寻或寻求认同。

### 第三步：写案例对应
- 明确写「案例的哪一部分 → 对应定义的哪一部分」，一句一处，不合并。
- 案例事实与虚构补全必须分开标注：事实标来源，补全标「教学假设」。
- 案例本身只作为样本，不要把一个案例的结论说成普遍规律。

### 第四步：摆原文证据
- 每条证据包含：`quote`（原文引文）、`sourceId`、`sourceTitle`。
- 引文必须是能回到原文的句子，不做二次概括后仍标为「原文」。
- 找不到可引用原文时，直接写「该点缺少可引用的原文证据」，并说明这对结论的限制。

### 第五步：组织案例对话
- 第一轮由**学生**提问，导师回应；交替至少 2 个来回。
- 每个来回只推进一个认知动作：提假设 → 要证据 → 给反例 → 收束为条件性主张。
- 对话要像真实课堂，不要写成问答式知识点清单。

### 第六步：收束
- `takeaway`：一条可迁移结论（换品类/换人群仍成立）；
- `boundary`：定义不成立或需要修正的条件；
- `checkQuestion`：只问一个，能检验学生是否真的理解。

## 2. 聊天里讲（不做附件时）

不改结构，只减深度：

1. 先给结论：这是什么现象、问题出在哪；
2. 拆 3–5 个知识点：概念 + 原文证据 + 为什么成立；
3. 给 2–3 条可迁移结论；
4. 说明边界条件；
5. 最后只问**一个**检查问题。

解释性回复不超过 5 个知识点；超出就拆成两轮。

## 3. 结构化模板（做附件时）

```json
{
  "kind": "case_study",
  "case": {
    "title": "案例标题",
    "subtitle": "一句话副标题",
    "summary": "2–3 句案例摘要",
    "companies": ["涉及企业"],
    "sourceNote": "来源说明：媒体名称与报道时间"
  },
  "knowledgePoints": [
    {
      "name": "知识点中文名",
      "definition": "1–3 句可判断的定义",
      "definitionSource": "教材章节或资料来源",
      "caseMapping": "案例哪一部分对应定义的哪一部分",
      "evidence": [
        { "quote": "原文引文", "sourceId": "来源标识", "sourceTitle": "来源标题" }
      ],
      "dialogue": [
        { "role": "student", "text": "学生第一轮提问" },
        { "role": "mentor", "text": "导师回应" }
      ],
      "takeaway": "一条可迁移结论",
      "boundary": "定义不成立的条件",
      "checkQuestion": "一个检查问题"
    }
  ],
  "transfer": ["换品类/换人群/换情境后的迁移结论"],
  "boundaries": ["整份分析的适用边界"],
  "usageNote": "使用说明：哪些是事实，哪些是教学假设"
}
```

新闻分析复用同一结构，把 `case` 换成新闻卡（标题、媒体、时间、链接），并在 `usageNote` 中标注「新闻候选未被人工审校时，不作为出题锚点」。

## 4. 顺序与自检

1. **判断类型**：概念解释 / 案例精讲 / 新闻分析。三者结构同构，深度不同。
2. **取材料**：优先用课程知识点定义、已入库案例与新闻来源；材料不足时明确列出缺什么。
3. **写定义**：先把定义写对，再动案例。定义写不清就不往下走。
4. **写映射与证据**：逐条对应，逐条标来源。
5. **写对话**：学生先问，导师后答，2 个来回以上。
6. **写结论、边界、检查问题**：边界必须具体到「什么条件下不成立」。
7. **自检**：有没有无来源断言、有没有把假设写成事实、有没有超出学生当前章节太多。

## 5. 边界

- **不编造**：不虚构案例细节、数据、引文与报道时间；宁可说「资料不足」。
- **不替代学生判断**：给定义、给证据、给反例，不替学生下最终结论。
- **不越界评价**：这里只提供材料与证据候选，水平判断见 `competency-rubric`。
- **不混淆来源类型**：教材、新闻、知识点、教学示例必须分别标注，学生要能核对原文。
- **不把新闻候选当已审材料**：未人工审校的新闻只能作为展示材料，不作为教学映射或出题锚点。
- **不做长讲义**：单一概念不自动扩写邻近章节；学生追问「那学习呢」时只展开该知识点。
- **不输出内部 ID**（如 `kp_*`），只写知识点中文名。
