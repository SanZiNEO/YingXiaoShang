# 出题与批改手册

> 用在：学生要出题、交卷、批改、逐题解析、题库去重。
> 信条：**题目服务于诊断，不服务于分数。** 题目要么测出学生在哪里想错了，要么不必要。

## 1. 出题

### 按需出题
学生要几道就几道（上限 30），不擅自缩水，不悄悄凑数。

### 题型搭配
概念辨析、情境判断、数据解读、取舍论证四类搭配，避免全是记忆题。

| 题型 | 测什么 | 设计要求 | 不应作为主证据 |
|---|---|---|---|
| 概念辨析 | 是否真理解定义边界 | 给正例与反例，要求判断并说明理由 | 只答对选项 |
| 情境判断 | 能否在新情境中迁移 | 换品类、换人群、换渠道，保留核心结构 | 直接套教材原句 |
| 数据解读 | 能否读指标、识因果陷阱 | 给简表或指标组合，问「能推出什么、不能推出什么」 | 只报数字 |
| 取舍论证 | 能否给条件性主张 | 给约束与冲突目标，要求说明取舍标准与失败模式 | 只列优缺点 |

**硬性要求：**

- 选择题必须配「为什么」的追问位，否则只能作为线索级证据。
- 判断题不能只考名词，要考「这个案例算不算」。
- 情境题要写清角色、约束、任务、交付物，隐藏信息要说明是否可假设。
- 每题标注所属知识点与对应能力维度，便于后续评价。

### 数量纪律

- 学生说「20 道」就出 20 道；上限 30 道。
- 出不满时最多续出 3 轮；仍不足则如实暴露 `requested / actual / shortfall`，**不许用低质量题凑数**。
- 不得擅自更改学生要求的数量；如需下调，先说明原因并征得同意。

### 写题顺序

1. **定范围**：确认章节与知识点；范围不清时按当前会话章节，不额外追问。
2. **配题型**：保证至少两类题型；单一知识点不出超过 5 道同质题。
3. **先写答案与解析，再写题干与干扰项**。干扰项必须对应真实迷思概念。
4. **去重自检**：与已有题目比对标准化题干；语义重复的换情境或换问法。
5. **交付**：答案折叠，标注「交卷前不显示答案」。

## 2. 批改

- **一次交卷、一条记录**：整卷作为一次提交处理，不把每题当成独立轮次。
- **逐题结构**：题号 → 对错 → 学生答案 → 标准答案 → 解析（错在哪一步）。
- **错误归因三级**：概念混淆 / 证据使用不当 / 推理跳跃。归因要指向可修正的动作。
- **部分失败**：只重试失败题，已成功的不重复提交；重复或并发交卷保持幂等。
- **不给虚假精确**：开放题用 rubric 描述水平，不给「87 分」这类伪精确分数。
- 批改后给**一个**改进行动即可，不写长篇讲义。

## 3. 证据候选

从学生原话与作答中抽取，每条包含：

```json
{
  "type": "explanation | decision | tradeoff | data_interpretation | revision | reflection",
  "quote": "学生原话或作答原文",
  "knowledgePoint": "知识点",
  "competency": "问题建构 | 证据与假设 | 决策与取舍 | 沟通与影响",
  "strength": "B | C",
  "note": "这条证据能说明什么、不能说明什么"
}
```

**强度纪律：**

- 一道选择题的正确答案只能算 C 级线索，**不建立高等级能力结论**。
- 学生只给结论、没有假设与推理的，不产出证据。
- 学生自报「我学会了」不作为证据。
- AI 代写或重度润色的文本不作为证据。
- 单轮能给的最高强度是 B；A 级需要独立、跨情境、带追问或答辩的表现性任务，由教师确认。

## 4. 边界

- **不编造题目依据**：题干涉及的事实、数据、新闻必须来自已核材料；无来源就不用。
- **不给最终能力等级**：出题环节只给证据候选与题目表现，等级判断见 `competency-rubric`。
- **不泄露答案**：交卷前任何导出、正文、摘要都不得包含答案。
- **不迎合数量**：宁可暴露缺口，也不用重复题、无解题、超纲题凑数。
