# 四维能力 rubric 与证据分级

> 用在：学生问「我学得怎么样」、要成长卡、要阶段验收；出题环节抽证据时也照这里的强度纪律。
> 重要：rubric 应由任课教师与评价专家共同定稿。未定稿前，所有等级只作形成性参考，不用于成绩认定。

## 1. 为什么商科需要另一套评价方式

商科的学习对象是劣构问题：问题边界、目标与约束常常不清晰，同一框架换行业、换阶段就可能失效，专家之间也常分歧。因此：

1. **评判断，不评答案**：看学生如何在不确定下形成有条件的主张。
2. **评过程，不评成品**：看追问链、假设变化、修订理由、答辩表现。
3. **评迁移，不评记忆**：看换行业、换情境、换约束后是否仍能工作。
4. **评个体，不评团队平均**：个人证据与团队产出分开记录。
5. **评成长，不评排名**：看水平移动与稳定性，不做公开横向比较。
6. **评可行动性，不评框架熟练度**：建议能否落地，是否考虑资源、组织、风险与伦理。

## 2. 四个核心维度

| 维度 | 定义 | 核心问句 | 不测什么 |
|---|---|---|---|
| 问题建构 | 能否定义真正的问题、边界、约束与利益相关者 | 你要解决的到底是什么问题？为什么不是另一个？ | 是否记住框架名称 |
| 证据与假设 | 能否区分事实/假设/观点，选择证据，识别偏差 | 这个判断依赖哪些假设？什么证据能推翻它？ | 资料堆砌数量 |
| 决策与取舍 | 能否形成有条件的主张，比较替代方案，处理风险与伦理 | 在什么条件下选 A 而不是 B？失败模式是什么？ | 结论是否「听起来正确」 |
| 沟通与影响 | 能否针对受众组织论证、回应质疑、推动行动 | 决策者最关心什么？你怎么回应反对意见？ | 口才、术语、PPT 美观度 |

可选第五维：**元认知与适应性**——能否根据反馈调整、识别自身盲区、说明自己不确定什么。MVP 不强制。

## 3. 四级表现描述

### 3.1 问题建构

| 水平 | 表现 |
|---|---|
| L1 复述题目 | 把案例中的现象直接当问题；边界模糊；未识别关键利益相关者。 |
| L2 框架套用 | 能用 SWOT/5C/波特等拆解，但框架与情境匹配度低，遗漏关键约束。 |
| L3 情境化建构 | 能区分症状与根因；界定决策边界、时间尺度、资源约束；识别主要利益相关者及其诉求。 |
| L4 批判性建构 | 能质疑题目预设；提出替代问题框架；说明框架适用边界与盲区；预判不同建构会导致的不同决策。 |

### 3.2 证据与假设

| 水平 | 表现 |
|---|---|
| L1 | 观点堆砌，事实与假设混用，无法指出判断依赖什么。 |
| L2 | 有证据意识，但选择标准不清；引用材料与结论之间缺少连接。 |
| L3 | 证据链完整，区分事实/假设/推断，能做基本估算，说明证据来源与口径。 |
| L4 | 主动寻找反证，做敏感性与情景分析，明确说明证据缺口与结论边界。 |

### 3.3 决策与取舍

| 水平 | 表现 |
|---|---|
| L1 | 单一建议，无条件、无替代、无风险说明。 |
| L2 | 能列选项比较，但停留在优缺点清单，没有判断标准。 |
| L3 | 明确标准与权重，给出条件性建议，考虑风险与实施路径。 |
| L4 | 设计触发条件与退出机制，处理利益相关者冲突与伦理张力，说明失败模式。 |

### 3.4 沟通与影响

| 水平 | 表现 |
|---|---|
| L1 | 信息倾倒，无受众意识，不区分主次。 |
| L2 | 结构清晰，但未针对受众调整，未预判质疑。 |
| L3 | 受众适配，能回应质疑，语言克制，结论与依据对应。 |
| L4 | 能处理反对意见，建立可信度，明确下一步与责任归属。 |

## 4. 证据体系

### 4.1 可用证据类型

| 类型 | 能说明什么 | 局限 |
|---|---|---|
| `explanation` 解释 | 是否理解机制与因果 | 受表达能力影响 |
| `decision` 主张 | 是否形成有条件判断 | 可能只有结论 |
| `tradeoff` 取舍 | 是否比较替代、识别风险 | 容易停留在清单 |
| `data_interpretation` 数据解读 | 指标选择、因果谨慎 | 依赖数据质量 |
| `revision` 修订 | 是否能据反馈改进 | 需版本记录 |
| `reflection` 反思 | 元认知与校准 | 自报偏差 |

### 4.2 强度分级

| 级别 | 定义 | 例子 | 用途 |
|---|---|---|---|
| A | 独立、跨情境、有追问或答辩的表现性任务 | 新案例 + 口头答辩 | 可支撑结论 |
| B | 有过程记录的复杂任务 | 备忘录 + 修订历史 + 一次追问 | 可支撑，需注明条件 |
| C | 单次对话、课堂发言 | 一次案例讨论 | 仅作线索 |
| D | 参与度、出勤、自评 | 打卡、字数、PPT 页数 | **不作能力证据** |

**原则：D 级不能单独支撑任何结论；C 级只能作为线索，不能作为定论。**

### 4.3 无效证据与反证据

不能作为能力证据：

- 出勤率、发言次数、聊天时长、字数、PPT 页数；
- 框架名称的堆砌数量；
- 只有结论、没有假设与推理的文本；
- 经 AI 重度润色、无法追溯学生本人思考的成品；
- 学生自报的「我学会了」「我进步了」；
- 团队总分直接分配给个人。

反证据同样重要：**能指出自己结论的边界、失败模式、反例，往往比多给一个正确结论更能说明能力。** 反证与「尚未观察到」必须写进成长卡。

## 5. 什么叫进步

> 在**可比任务**上，学生**独立表现**所处的水平发生了移动。

| 尺度 | 看什么 | 证据 |
|---|---|---|
| 微观（单次会话） | 是否从卡住到能自己走一步 | 提示梯度、修订理由 |
| 中观（单元/3–4 周） | 同一能力换情境后是否仍成立 | 平行案例、口头答辩 |
| 宏观（整门课） | 水平移动 + 稳定性 + 证据密度 | 证据账本、检查点、教师复核 |

必须允许三种结论：**进步、停滞、证据不足**。

### 六种典型位移

| 从 | 到 | 可观察证据 |
|---|---|---|
| 套框架 | 选框架、改框架、说明边界 | 能解释「为什么不用 SWOT」 |
| 给答案 | 给有条件的主张 | 能说出「在 X 假设下选 A，否则选 B」 |
| 做分析 | 做可执行决策 | 有资源、组织、时间、风险安排 |
| 单点思维 | 系统/利益相关者思维 | 能识别二阶效应与冲突 |
| 回避不确定性 | 量化/管理不确定性 | 有情景分析、敏感性、触发条件 |
| 自我表达 | 受众适配与影响 | 能回应决策者关切与反对意见 |

## 6. 成长卡结构

不要输出单一分数，输出「能力证据卡」：

```
能力：决策与取舍
当前水平：L3（中等置信）
变化：L2 → L3，主要发生在第 6–9 周
支持证据：第 4 周案例 A 备忘录（L2）；第 8 周案例 B 口头答辩（L3）；第 10 周反事实追问（L3）
反例/待验证：在资源约束下仍未给出退出条件；尚未观察到跨行业迁移
建议：下一次练习「触发条件与失败模式」
证据强度：中（3 条独立证据，1 次人工复核）
```

### 置信度校准

| 置信度 | 条件 |
|---|---|
| 高 | ≥2 条 A 级证据，跨情境，且有一次人工复核 |
| 中 | 1 条 A 级或 ≥2 条 B 级证据，情境有限 |
| 低 | 仅 C 级证据，或证据全部来自同一任务 |

### 写作纪律

- 结论三选一：进步 / 停滞 / 证据不足；
- 每个维度最多一个等级，必须配置信度；
- 不给总分、不给排名、不做学生间横向比较；
- rubric 未定稿、缺少人工复核、样本仅单次，必须写进 `caveats`；
- 证据不足就写「证据不足」，不用「有待提升」掩盖。

### 结构化模板（学生要一份成长卡时）

```json
{
  "kind": "growth_card",
  "conclusion": "进步 | 停滞 | 证据不足",
  "scope": "章节或时间段",
  "dimensions": [
    {
      "name": "决策与取舍",
      "level": "L3",
      "confidence": "中",
      "change": "L2 → L3，主要发生在第 6–9 周",
      "supportingEvidence": [
        { "date": "第 8 周", "task": "案例 B 口头答辩", "quote": "学生原话", "strength": "B", "level": "L3" }
      ],
      "counterEvidence": ["在资源约束下仍未给出退出条件"],
      "notYetObserved": ["尚未观察到跨行业迁移"],
      "nextPractice": "下一次练习触发条件与失败模式"
    }
  ],
  "evidenceStrength": "中：3 条独立证据，1 次人工复核",
  "caveats": ["rubric 尚未经任课教师定稿，等级仅作形成性参考"]
}
```

写完必须配一个**迁移任务**：一个具体动作，能验证这个结论是否稳定。

## 7. 评价流程（供参考）

```
学生作答/对话 → 证据抽取 → 剔除 D 级 → 分级 A/B/C → rubric 定位
→ 反证检查 → 置信度标注 → 成长卡 → 教师复核（可选）→ 迁移任务
```

**申诉与校准：** 学生可查看「系统记得我什么」并提出更正；教师可复核等级；分歧点记录在案，不追求虚假共识。
