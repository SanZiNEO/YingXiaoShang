# Data

- `normalized/` is generated by the TypeScript pipelines from the read-only
  course materials under `resources/`. Treat it as the ingestion output, not as
  hand-edited source.
- `legacy/` holds the earlier Python-era extracts. It is reference-only; the
  product does not read it at runtime except for the chapter 3–5 granular
  knowledge-point merge during resource ingestion.

Regenerate:

```sh
pnpm run pipeline:resources
pnpm run pipeline:news
RESET_DB=1 pnpm run db:seed
```

`resources/` is untracked and read-only. Do not commit the source textbook or
news full text. For a public release, keep only metadata, links, and short
snippets. The app home defaults to `LEARNING_AGENT_HOME` (`<repo>/.learning-agent` in development).
