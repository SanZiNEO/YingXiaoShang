## 一、一句话说清我们怎么推进

**按「学生能不能用」分阶段推进，不按技术模块推进。**


## 三、P0 / P1 / P2 是什么（不是功能清单）

这是**紧急度分级**，我和复核代理内部用的：

| 级别 | 定义 | 处理规则 |
|---|---|---|
| **P0** | 学生会卡死、数据会错、发出去会出事 | 马上修，修完才允许发 |
| **P1** | 明显退化或误导（假停、拿旧新闻当最新） | 本轮修，不排期 |
| **P2** | 打磨，不影响走完流程 | 记着，攒一批一起做 |

**现状（2026-11-07 复核后按代码重核，不按自述）**：

- **已修完**：启动失败无窗口、停止按钮假停与消失、工具事件撤字、空返回丢正文、
  交卷重试旧答案、新会话旧 sessionId、空题目集无引导、错误文案 400 误判、
  新闻联网过慢、历史无预算、出题不入库、记录器空记录、题型不统一。
- **仍未修（明确挂着，不假装完成）**：
  1. `maxRounds=10` 固定轮次 + 收口轮（F03）—— 应随原生 loop 删除，属 B 轮
  2. 工具参数无统一 schema 校验（F07）
  3. 读正文硬切 4k/12k 且无「可续读」提示（F15）
  4. `skills/case-coach` 未接注册表，且是死文件（F14）
  5. 清理项：`news-lab.ts` 死文件、启动自检提示会被首条消息清掉、
     `App.tsx` 残留按角色分派的分支、3 处文档行号指错

## 四、阶段重定义（2026-11-19，按真实目标改）

**为什么改**：9 月定的 M1「一个人能顺利用完一轮」**已经达成了**（单机版闭环）。
现在真实目标变了：**保底拿到校内服务器上的网页版，理想拿到微信小程序**。
所以阶段不能按「功能多少」排，要按「谁能用」排。

```
P0  单机原型（已完成）
M1  校内网页版：学生用浏览器/手机就能用，老师能看到全班
M2  一个班真跑：并发、备份、日志、额度、发布流程
M3  微信小程序：资质、备案、域名、内容安全
```

### 各阶段的判据（做到了就是做到了，不含糊）

| 阶段 | 判据 | 现在 |
|---|---|---|
| **P0 单机原型** | 2 个没用过的人不看说明走完一轮（问答→出题→交卷→看档案） | ✅ 已达成（1105i 包） |
| **M1 校内网页版** | 40 人同时在线不崩；老师打开一个页面能看到本班错题分布；学生用学号登录 | 🔵 进行中（0 行服务端代码） |
| **M2 一个班真跑** | 一个班用一个完整作业周期，无 P0；断网/换机/重装都能恢复 | ☐ |
| **M3 小程序** | 微信里打开，完成一次完整练习；内容安全与隐私协议过审 | ☐ 依赖资质 |

> **P0 单机版不是废弃品**：保留两个用途——① 给老师/信息办演示（不需要联网、不需要服务器）；
> ② 服务器故障时的离线兜底。它**不再是交付主线**。

## 五、M1 拆解：校内网页版（当前主战场）

### 5.1 关键排期结论：**不用等服务器就能开工**

学校批服务器要 1–2 周，备案要 2–4 周。但这几件事现在就能做，做完等服务器到了直接部署：

| 编号 | 事项 | 谁 | 为什么现在能做 | 估时 |
|---|---|---|---|---|
| 1.1 | **服务端骨架**：把 `packages/agent` 装进一个 Node HTTP 服务，Electron 与 Web 共用同一套业务 | 💻 | 本地 Docker 起同一套，和服务器环境一致 | 3–5 天 |
| 1.2 | **数据层**：SQLite 单写 → PostgreSQL（或先保持 SQLite 单实例，多用户靠队列） | 💻 | 本地容器跑 PG 验证 | 2 天 |
| 1.3 | **Web 前端**：现有 React 渲染层把 `window.learning`（IPC）换成 HTTP 客户端 | 💻 | 接口照现有 invoke 方法一一对应，不改业务 | 3–5 天 |
| 1.4 | **账号**：先做「学号 + 口令」兜底，等学校统一认证接口到位再换 | 💻🧑‍🏫 | 兜底方案不依赖学校，接口到位只换一层 | 2 天（兜底）/ 1 天（对接） |
| 1.5 | **新闻库服务端化**：Python 采集服务 + 打标流水线 | 💻 + 杨 | 他已完成 80%（40+ 源、控制面 API、bench） | 2–3 天（Docker 化 + 调度） |
| 1.6 | **老师端 v0**：班级列表 + 单个学生时间线 + 错题分布 | 💻🧑‍🏫 | 需要魏老师回答 5.2 的 6 个问题 | 3–5 天 |
| 1.7 | ~~桌面端新闻兜底~~ | 💻 | ✅ 2026-11-19 已完成（`packages/news/src/fallback.ts`，19+8 条断言，含接线） | 已完成 |

**合计约 2–3 周**（我一个人推的话）。如果杨泽易并行做 1.5 和他手上的测试，能压到 2 周。
