## 一、一句话说清我们怎么推进

**按「学生能不能用」分阶段推进，不按技术模块推进。**

```
M1  一个人能顺利用完一轮（问答→查资料→出题→交卷→看档案）   ← 我们在这里
M2  一个班能发出去（老师能看、装得上、出问题能救）
M3  多端（手机网页版 / 微信小程序 / 全班共用新闻库）
```

中间只允许一种插入：**真实学生的反馈**。它优先级最高，插进来先修，修完回主线。

**明确不做**：不为「以后可能用到」提前搭架子；不重构能跑的代码；不追求技术先进。

## 三、P0 / P1 / P2 是什么（不是功能清单）

这是**紧急度分级**，我和复核代理内部用的：

| 级别 | 定义 | 处理规则 |
|---|---|---|
| **P0** | 学生会卡死、数据会错、发出去会出事 | 马上修，修完才允许发 |
| **P1** | 明显退化或误导（假停、拿旧新闻当最新） | 本轮修，不排期 |
| **P2** | 打磨，不影响走完流程 | 记着，攒一批一起做 |

**现状（2026-11-07 复核后按代码重核，不按自述）**：

## 四、M1 详细拆解（一个人能顺利用完一轮）

> 判据：**找 2 个没用过的人，不看说明，各走完一轮**（问答 → 出题 → 交卷 → 看档案），中间不需要你口头指导。

| # | 事项 | 谁 | 具体做什么 | 大约耗时 |
|---|---|---|---|---|
| 1.1 | 清 4 条 P2 | 💻 | 见上节四条，逐条修 + 补断言 | 半天 |
| 1.2 | 出题质量抽检 | 💻 + 🧑‍🏫 | 我出 10 组题，**魏老师看答案对不对、难度合不合适**（她教这门课，只有她能判断） | 我半天 + 她 1 小时 |
| 1.3 | 空状态引导 | 💻 | 第一次打开时给 3 个可直接点的示例问题，不要空白输入框 | 半天 |
| 1.4 | 新装机器自检清单 | 💻 + 🧑‍🏫 | 在一台**没装过任何开发工具**的电脑上解压试跑；需要老师提供一台办公电脑或学生电脑 | 我 2 小时 + 借机器 |
| 1.5 | 真实试用（M1 的验收） | 🧑‍🏫🎓 | **魏老师安排 2 个学生**，各用 40 分钟，你在旁边只看不教，记录卡在哪 | 她协调 + 我 2 小时 |

**M1 完成后你手上有什么**：一个能给学生用的包 + 一份「2 个学生实际怎么用」的记录。这份记录是后面所有决策的依据。

**M1 的最大风险**：1.5 一直排不上。那就等于我们在盲猜。

## 五、M2 详细拆解（一个班能发出去）

> 判据：**老师自己能装、能看、能回答「这个学生这周做了什么」**。

### 5.1 先要老师拍板的事（不做这步，老师端写出来是废的）🧑‍🏫

以下 6 个问题必须魏老师回答，否则老师端 0 行代码没法动：

| # | 要问的问题 | 为什么要问 | 备选答案 |
|---|---|---|---|
| Q1 | 你一周要看几次学生进度？ | 决定是做「实时看板」还是「每周一份汇总」 | 每天 / 每周 / 只在期末 |
| Q2 | 你最想看到的是「谁没做」还是「谁做得怎么样」？ | 决定首页排序逻辑 | 缺勤优先 / 质量优先 |
| Q3 | 要不要给学生的答案打分/写评语？ | 决定要不要做批注功能（工作量大） | 要 / 不要 / 只要标记可疑 |
| Q4 | 成绩要导出成什么格式？ | 决定导出功能 | Excel / 直接发微信截图 / 打印 |
| Q5 | 学生数据能不能出这台电脑（上云）？ | **涉及隐私合规**，决定架构 | 只能本地 / 可以上云 |
| Q6 | 你会用 U 盘/网盘发给学生，还是让学生自己下？ | 决定更新机制怎么做 | U 盘 / 群文件 / 网盘链接 |

> **这 6 个问题我可以帮你写成一张微信消息，直接发给魏老师。**

### 5.2 技术工作（老师答完 Q1–Q6 才开工）

| # | 事项 | 谁 | 内容 | 耗时 |
|---|---|---|---|---|
| 2.1 | 老师端界面 | 💻 | 班级 → 学生列表 → 单个学生时间线（问了什么、出了什么题、答得怎样） | 3–5 天 |
| 2.2 | 数据汇总 | 💻 | 从每台机器的 `learning.db` 汇总到一个老师视图 | 1–2 天 |
| 2.3 | 更新机制 | 💻 | 换新包不丢数据，能提示「有新版本」 | 1–2 天 |
| 2.4 | 备份/恢复 | 💻 | 一键导出学情（一个文件），换机器能导入 | 1 天 |
| 2.5 | 失败恢复演练 | 💻 + 🧑‍🏫 | 真断网、真重装、真换机各演一遍；需要老师配合在一次课上真用 | 1 天 + 她 1 次课 |
| 2.6 | 发布渠道定下来 | 🧑‍🏫 | 决定包从哪发（U 盘？班级群？网盘？）以及**谁负责发** | 她定 |

### 5.3 一个绕不过去的问题 🧑‍🏫💰

现在用的是**你自己的 DeepSeek API key**。一个班 40 人真用起来：

- 费用会烧你的钱（按量计费）
- 一旦超额度，全班一起报错
- 学生看到的是你的账号

**必须老师决定**：是用她的经费申请一个 key，还是学校有统一的大模型服务，还是每个学生自己申请。
**这件事不定，M2 不能真发班。**

## 六、M3 详细拆解（多端，看反馈决定做不做）

> 前提判断：**只有两件事需要服务端** —— 新闻共享库、手机端。M1/M2 完全不需要服务器。

### 6.1 服务端新闻库

| # | 事项 | 谁 | 内容 |
|---|---|---|---|
| 3.1 | 买服务器 + 域名 | 💰🧑‍🏫 | 最便宜的云服务器就够（一年几百块）。**要老师决定谁出钱、用谁的账号备案** |
| 3.2 | 定时爬新闻 + 打标签 | 💻 | 复用现有 `refresh()`，一个 cron 每天跑一次 |
| 3.3 | 增量分发 | 💻 | 客户端启动时拉「上次之后的新文章」 |
| 3.4 | 降级方案 | 💻 | 服务端挂了要能退回「各自本地爬」，不能白屏 |

### 6.2 手机只读网页版

| # | 事项 | 谁 | 内容 |
|---|---|---|---|
| 3.5 | 手机网页版 | 💻 | 只能看：问过什么、出过什么题、档案进度。不能答题（省事且安全） |
| 3.6 | 登录 | 💻🧑‍🏫 | 用「学号+口令」还是「老师发链接」？**要老师定**，涉及谁能看到谁的数据 |

> **给学校看的完整版**：`docs/给信息办-需求清单.md`（v2 口径：**必须依赖学校服务器 + 学校 API 额度**，
> 保底校内网页版、理想微信小程序；含服务器规格、用量测算、需要回答的 10 个问题）。
>
> **谈判口径（重要）**：不要提「先在我们自己电脑上跑」。本地原型只用于证明技术可行，
> 不具备正式教学条件（数据分散、个人额度有限速、无日志与备份）。
> 一旦对方认为我们自己能解决，就不会批资源。

### 6.3 微信小程序（**最不确定的一环**）

| # | 事项 | 谁 | 现实情况 |
|---|---|---|---|
| 3.7 | 主体资质 | 🧑‍🏫💰 | 小程序要**企业/学校主体**才能做教育类目，个人主体做不了。**这是硬门槛，过不去就永远做不了** |
| 3.8 | ICP 备案 | 🧑‍🏫💰 | 域名备案 **2–4 周**，期间不能发布。要老师或学校出面 |
| 3.9 | 教育类目审核 | 🧑‍🏫 | 需要办学资质证明。**不确定学校愿不愿意为这个项目出证明** |
| 3.10 | 开发 | 💻 | 前面都过了才开始写（2–3 周） |

> **我的建议**：3.7–3.9 先别碰。先做 3.1–3.6（服务端 + 手机网页版），
> 用真实使用数据决定要不要花 1–2 个月去趟小程序的审批。

## 八、搜索能力现状（回答「我们到底有没有联网搜索」）

| 层 | 现状 | 实测 |
|---|---|---|
| 本地新闻库 | 5 个源定时爬（每台机器各自跑） | 快，但只有旧闻 |
| DeepSeek 搜索 API | **已接入** | **0.3–0.5 秒**返回真实结果（含正文） |
| 网页正文抓取 | 已接入，但问答路径**不再用它** | 30 秒/次 + 每秒限流 + 串行 = 这就是「卡三分钟」的元凶 |
| 触发策略 | 本地没命中 → 自动联网；问「最新」且本地 >2 天 → 也联网 | 端到端 1.9 秒 |

**结论**：联网搜索一直有，之前藏在默认关闭的开关后面，而且一触发就去爬网页。

**学长写爬虫要不要**：不要另写一套（会和现有 `refresh()` 冲突）。他帮忙最值钱的：
① 往 `packages/news/src/sources/` 加 2–3 个营销行业媒体源；② 做 M3 的服务端定时任务。

## 九、当前三大风险

1. **只有一台机器验证过**：新电脑、杀毒软件拦截、没网、开着代理 —— 都可能出问题（对应 M1-1.4）。
2. **key 是你自己的**：演示可以，发班不行（对应 5.3）。
3. **老师端是 0 行代码**：产品现在只有「学生侧」一半价值（对应 M2）。

## 十、建议的每周节奏

```
周一  我看一遍上周学生/老师反馈，定这周做什么（最多 2 件）
周二三 我写代码 + 自测 + 独立复核
周四  打包给你，你在一台干净电脑试
周五  找魏老师 10 分钟，确认她关心的事有进展
周末  休
```

**不要一次做 5 件事。** 一次 1–2 件，每件都做到「有断言、进包、真机验过」。
