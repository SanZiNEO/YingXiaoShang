## 手机端：离得比想象的远（诚实评估）

老师问过「小程序还是网页」。结论：**不是把桌面端改小，而是另立一个产品形态**。

缺的三块，缺一不可：

| 缺口 | 为什么必须 |
|---|---|
| **服务端** | 手机上没有本地 SQLite、没有本地文件。课程库、新闻库、题目、作答记录都得搬上去 |
| **身份与鉴权** | 桌面端可以不登录（一台机器一个人）；手机上必须知道「这是谁」，否则学情记忆全是错的 |
| **会话与并发** | 一个人可能同时开电脑和手机；现在没有账号概念，session 只在本机 |

**最省的一条路**（如果老师坚持要手机能看）：先做**只读的网页版**——能查知识点、能看历史对话，
不能出题、不能交卷。这样只需要服务端 + 登录，不需要把产物持久化搬上去。**大约 2–3 周**（不含买服务器）。

**不建议**：用「小程序套壳」把桌面端搬上去。桌面端依赖本地库和本地文件，套壳等于重写一遍后端。

## 事故记录：第一版在别人机器上报 `DEEPSEEK_API_KEY is not configured`（2026-11-05）

**现象**：作者本机能用且很快；同学机器上解压、启动、发消息就报
`Error invoking remote method 'learning:chat': Error: DEEPSEEK_API_KEY is not configured`。

**根因（两个，都往自己身上找）**：

1. **启动器用了 GBK 编码 + 中文路径字面量**。对方机器代码页不是 936 时，
   `营小商` 会被解成乱码，配置写进了一个名字错误的目录，软件当然读不到。
2. **说明没有明确「双击 bat 而不是 exe」**。exe 直接双击能启动界面，
   但不会写配置——用户很容易就是这么点的。

**修法**：

- 启动器改为**纯 ASCII 源文件**，中文路径用 Unicode 码点在 PowerShell 里拼：
  `[char]0x8425+[char]0x5C0F+[char]0x5546`（营小商）。这样文件编码与系统代码页都无关。
- 用临时 `APPDATA` 实测：目录名正确、`settings.json` 82 字节写入成功。
- 新增 `检查配置.bat`：打印配置目录、文件是否存在、能否解析、exe 是否在。
  出问题让用户截这一屏，比来回猜快得多。
- 说明首屏第一条改成「★ 一定要双击 .bat，不是 exe」，并写清报错第一反应是跑 `检查配置.bat`。

**教训（写进检测包经验）**：**面向非技术用户的交付物，不能依赖文件编码与代码页。**
脚本里出现中文路径就该警觉——要么用码点/环境变量拼，要么让脚本完全不碰中文。

## 事故记录 2：别人机器上「转 5 分钟才出答案」（2026-11-05）

**现象**：配置修好后能出结果，但要 5 分钟。同一份包在作者机器上秒回。

**排除法结论**：不是配置（配置错会立刻报 `not configured`，不会转圈），
不是产品逻辑（同一份二进制），**是那台机器的网络路径**。

**更正（同一份 key、同一个端点，只差代理）**：

```
直连（普通网络） : HTTP 200  0.78s
走代理（作者环境）: HTTP 200  0.86s
```

**所以跟代理无关，也不需要梯子。** 之前把「作者机器开着代理」当成原因是错的，
那只是环境巧合。作者机器直连同样快（778ms）。

实测基线：

```
DNS         : 只有 IPv4（111.32.200.78 / 39.156.8.67），没有 AAAA
TCP 443     : 32 ms
/chat/completions 直连 : HTTP 200 / 778 ms
```

**三种典型成因**（都要靠 `检查网络.bat` 区分）：

| 成因 | 特征 | 处理 |
|---|---|---|
| 系统代理开着但代理没启动 | `ProxyEnable=1` 且 TCP/API 超时 | 关系统代理，或启动 VPN 客户端 |
| 校园网/运营商到 DeepSeek 绕路或限速 | TCP 慢、API 慢但能通 | 换手机热点对比 |
| IPv6 优先但不可达 | TCP 卡 2 分钟级后回退 | 与上一条同样处理；根治要在代码里 `ipv4first` |

**为什么软件不报错只转圈**：请求没有超时、终态判断只认 `finish_reason`（审计 F01/F02）。
网络不动时界面就没有任何反馈——这是 D 轮要修的，不是这一版的运维问题。

## 改用启动器 exe：为什么这次能「双击 exe 就行」（2026-11-05）

**问题**：上一版要双击 `启动营小商.bat` 才写配置。用户直接双击 `营小商.exe` 会报
`DEEPSEEK_API_KEY is not configured`——因为 Electron 只从 `userData/settings.json` 读 key，
而全新机器上这个文件不存在。

**做法**：把真的主程序改名 `营小商-core.exe`，用一个 **6 KB 的原生启动器**占用 `营小商.exe`
这个名字。启动器做三件事：

1. 确保 `%APPDATA%\营小商\` 存在；
2. 若 `settings.json` 不存在，从同目录复制一份过去（已存在则不覆盖，避免冲掉用户自己改的 key）；
3. 启动 `营小商-core.exe`，并在桌面建一个带原图标的快捷方式。

**关键点**：

- 目标框架 `net48`（Win10/11 自带），**不需要装任何运行时**；
- 用 PowerShell `Add-Type` 编译，**不需要装 SDK**；
- 目录名用 Unicode 码点拼（`\u8425\u5C0F\u5546`），**与文件编码、系统代码页无关**；
- 有异常弹中文对话框，不会静默失败。

**实测**：删除真实 `%APPDATA%\营小商\settings.json`（模拟新机器）→ 双击 `营小商.exe`
→ 文件被自动写回、内容正确 → 恢复原配置并比对一致。

**仍不能保证的**：速度。快慢取决于那根网到 DeepSeek 的链路，本机直连实测 0.78 秒；
校园网可能慢几十倍，而这版软件**没有超时**（审计 F01/F02），慢的时候只会转圈。
所以包里保留 `检查网络.bat`：一屏就能看出是「网慢」还是「软件问题」。
