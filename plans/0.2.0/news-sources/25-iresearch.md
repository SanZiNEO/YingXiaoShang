# 25 艾瑞咨询

> 入口：https://www.iresearch.com.cn/（研究咨询主站） / http://news.iresearch.cn/（艾瑞网资讯）
> 摸底时间：2026-11-18
> 摸底方式：veddata（真实浏览器 + 网络捕获）
> 状态：可打开，报告接口可读，下载需留资

## 一、这是什么站

- **定位**：互联网/新经济研究咨询机构，行业报告、市场规模、用户研究
- **主体**：艾瑞咨询（iResearch）
- **商科相关**：**高**（互联网广告、电商、消费行业研究，报告可作教学数据源）
- **内容形态**：研究报告 + 艾瑞指数 + 资讯（艾瑞网）
- **更新频率**：报告按月/季；艾瑞网日更

## 二、页面与技术形态

- **框架**：Vue（`__SVG_SPRITE__`、router 链接）
- **渲染**：1507 字符、80 链接，页面以导航与服务介绍为主
- **风控**：无验证码；**下载报告要留姓名/手机号**（`input#trueName`）
- **登录**：下载留资，浏览不强制

## 四、探索记录

1. 打开主站：正常，导航含"研究报告 / 研究咨询 / 行业方案 / 产品服务 / 艾瑞指数"。
2. 只捕获 1 个内容接口 `GetIndexReport`（72 字段），其余是 SVG 雪碧图变量。
3. 页面有留资表单（姓名 input），说明报告下载要换线索。
4. 另确认：`news.iresearch.cn` 是独立资讯站（HTML），本次未单独打开。

## 五、结论：怎么抓最省事

- **推荐路径**：`GetIndexReport` 抓报告目录（标题+行业+日期）→ 详情页取摘要；
- **资讯补充**：`news.iresearch.cn` 按 HTML 抓，量比报告大；
- **注意**：全文 PDF 需留资，不建议自动化提交表单（合规风险）。
