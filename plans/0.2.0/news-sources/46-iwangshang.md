## 四、探索记录

1. 先试旧域名 `iwshang.com` → `ERR_NAME_NOT_RESOLVED`（**域名已废**）。
2. 检索确认新域名 `tianxiawangshang.com`，打开正常。
3. 抓到 4 个 `media.tianxiawangshang.com` 接口，明文 GET，无签名。
4. `content/list` 被调用 3 次（对应 3 个 tab），说明一个接口带栏目参数即可取多栏。

## 五、结论：怎么抓最省事

- **推荐路径**：`content/list`（分栏目）→ 详情页；
- **注意**：**适配器里的域名要改成 `tianxiawangshang.com`**，否则会一直 0 条；
- **红利**：接口明文 + 栏目清晰，很适合做电商方向的主力源。
