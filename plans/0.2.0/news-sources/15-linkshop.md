- **定位**：零售行业门户，商超、百货、电商、连锁品牌的经营动态

- **内容形态**：行业新闻 + 门店动态 + 数据榜单
- **更新频率**：高频（适配器每轮能拿到新稿）

## 二、页面与技术形态

- **框架**：传统门户（HTML）

## 四、探索记录

1. veddata 打开 `http://www.linkshop.com/` → `ERR_BLOCKED_BY_CLIENT`（不是超时、不是验证码）。
2. 换 `https://` 与 `m.linkshop.com` 同样被拦 → 是**客户端拦截规则**（浏览器/插件黑名单），不是站点问题。
3. 已有适配器实测正常：153 条、973ms，说明服务端 HTTP 完全可达。

- **注意**：既然服务端可直连，这个源属于"最省成本"的一类，无需改造。
