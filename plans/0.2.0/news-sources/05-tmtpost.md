# 05 钛媒体

> 入口：https://www.tmtpost.com/
> 摸底时间：2026-11-18
> 摸底方式：veddata（真实浏览器 + 网络捕获）
> 状态：可用；文章 SSR，另有独立创投事件库接口

## 一、这是什么站

- **定位**：科技与产业财经媒体，"打开科技 打开财富"，覆盖 AGI、出海、科股、创投、消费、大健康
- **主体**：钛媒体集团
- **商科相关**：**中高**（科股/创投/消费/金融频道对口；大量科技硬新闻需筛）
- **内容形态**：资讯 + 深度 + 专题 + 直播 + 创投事件库
- **更新频率**：首页当日多条

## 二、页面与技术形态

- **框架**：传统 SSR + 独立子域接口（`tbn.tmtpost.com`、`api.tmtpost.com`）
- **渲染**：首屏 6947 字符、378 个链接，文章标题与频道全部可读
- **风控**：本次未见验证码
- **登录**：阅读不强制，PRO 内容有会员

## 四、探索记录

1. 打开首页：正常，频道导航极长（20+ 频道），说明内容量大。
2. 捕获到 `get_api_event_list_first`，返回的是**投融资事件**（32400 条总量、limit 10），字段多为图片化标签（金额/币种以图片 URL 形式返回，需 OCR 或映射）。
3. 文章列表本身没有独立接口，应该在 HTML 里。
4. `api.tmtpost.com` 另有作者推荐、订阅状态接口。

## 五、结论：怎么抓最省事

- **文章**：走 HTML 列表 + 详情页（最稳）；
- **投融资事件**：直接调 `tbn.tmtpost.com` 那个接口，`country=444`，可翻页拉全 3.2 万条，是**商科教学的好素材**（融资轮次、金额、行业）；
- **注意**：事件接口大量字段是图片（`amount_descriptive` 等返回 png 链接），说明前端用图片渲染金额/币种，要取值得映射或 OCR，直接用成本高。
