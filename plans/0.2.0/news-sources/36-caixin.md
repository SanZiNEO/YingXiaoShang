# 36 财新

> 入口：https://www.caixin.com/
> 摸底时间：2026-11-18
> 摸底方式：veddata（真实浏览器 + 网络捕获）
> 状态：可打开，**内容有付费墙**；数据接口丰富

## 一、这是什么站

- **定位**：财经调查报道 + 经济数据（财新数据通），深度与敏感选题见长
- **主体**：财新传媒
- **商科相关**：**极高**（公司调查、金融、宏观）
- **内容形态**：深度稿（订阅制）+ 数据通 + 视频 + 博客
- **更新频率**：日更

## 二、页面与技术形态

- **框架**：SSR + `gateway.caixin.com`（内容/视频）+ `cxdata.caixin.com`（数据）
- **渲染**：4408 字符、329 链接
- **风控**：无验证码
- **登录/付费**：**强付费墙**（订阅/登录/机构订阅），非订阅只能看开头

## 四、探索记录

1. 打开首页：正常，头部有"商城/订阅/登录/数据通"。
2. 抓到 `cxdata` 三个数据接口（K 线 1545 字段最大）+ 视频接口。
3. 文章正文没有独立内容接口，走 HTML；非订阅只给导语。
4. 结论：**数据可用，正文不可用**。

## 五、结论：怎么抓最省事

- **推荐路径**：只取**标题 + 导语 + 链接**（列表页足够），正文不抓；
- **不要**：不要尝试绕过付费墙（合规风险）；
- **附加值**：`cxdata` 的宏观/行情数据可做"市场背景"素材（如果授权允许）。
