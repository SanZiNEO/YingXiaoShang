## 2. 根因（管线侧）

`pipeline/lib/knowledge.ts` 的 `pickDefinition()`：

```ts
function pickDefinition(paragraphs: string[]): string {
  const substantial = paragraphs.find(/* 长度≥20 且以句号结尾或含"是指" */)
  if (substantial) return substantial          // ← 只返回第一段，其余全丢
  ...
}
```

只用 `.find()` 取第一个「实质段落」，同一知识点下的后续小点全部丢弃。
对照教材，这三条的第一小点恰好只是"评估细分市场""里斯和特劳特""品牌化战略"——于是丢了核心。

---

## 3. 修复方案（二选一，建议 B）

**A. 快速修：把段落拼起来**

```ts
const substantial = paragraphs.filter(/* 同样的判定 */)
if (substantial.length) return substantial.join('')
```

代价：定义会从「1–3 句」变成 200–400 字，与规范 §4.1 冲突，且不利于卡片展示。

**B. 按数据模型修（推荐）**

- `definition` 保持短句（现行逻辑不变）；
- 被丢弃的后续小点，按规范已有的 `parent_id` 拆成**子知识点**（如 `kp_ch07_929b6ddd` 下挂「无差异营销 / 差异化营销 / 集中化营销」三条子点）；
- 或新增 `body` / `details` 字段存放完整正文，`definition` 只做摘要。

这样既保住「定义 1–3 句」的规范，又让 STPB 分析有可讲的机制层内容。
