## 3. 文档与代码对不上

1. **`subagents.ts` 被三次写成「已删除」**（`营小商-MVP-v2.0.md:231`、`营小商-现状不足与可借鉴-v0.1.md:20`、`:88`）。实际 394 行存在，`answerQuestion` / `answerQuestionSet` 仍在用它。这是三条里唯一与运行路径相关的：文档说删了，代码还在跑。
2. **工具名过期**：`营小商-MVP-v2.0.md:181` 与 `营小商-多专家团模式参考-v0.1.md:81` 仍写 `load_reference`，实际是 `read_reference`。
3. **行数过期**：`营小商-MVP-v2.0.md` §8 写「手册 837 行」，实际 842 行（`artifact-schemas.md` 改写后未回填）。
4. **`.env.example` 注释过期**：仍写「real-LLM smoke check」（该脚本已删）；且没有列 `DEEPSEEK_BASE_URL`，而 `apps/desktop/src/main/llm.ts:85` 会读它。
5. **提示词工具清单不全**：`mentor.md` 点名了 8 个工具，没提 `read_kp`。工具本身自描述，影响很小，但清单与 `AGENT_TOOLS` 不一致。
6. **根 `README.md` 说「当前只有一份文档定义口径」**，而 `00-mvp/` 实际有 5 份、`docs/README.md` 也列了 5 份。**这一条在写入本文时已顺手改正**（改成一份产品口径 + 其余四份）。

## 5. 建议的清理顺序

按风险从低到高：

1. 删第 3、4、5 项（1429 + 804 + 58 行）。纯删除、零引用，删完编译一次即可验证。
2. 处理第 6、7 项（模板与 `renderTemplate`、`findings`）。涉及 `ArtifactService` 的公开方法与 `TeamTurnResult` 的字段，删之前确认前端与落库都不读。
3. 最后处理第 1、2 项（2073 + 3707 行）。这两项要先定一件事：`research` / `bp` / `questions` 是留给下一版，还是现在就退掉。删掉会同时失去 8 个产物类型里的大部分产出可能——虽然现在也没有调用点。

## 6. 怎么复查

结论都可以用静态检查复现，不需要跑服务：

```sh

grep -rn "from '@learning-agent/" --include=*.ts --include=*.tsx apps packages | grep -v node_modules

# 2. agent 包内每个文件的引用计数（0 即死文件）
grep -rn "from '\./" --include=*.ts packages/agent/src

# 3. 提示词工具名 vs 实际工具
grep -o '`[a-z_]*`' packages/agent/agents/mentor.md | sort -u
grep -o "name: '[a-z_]*'" packages/agent/src/tools/*.ts | sort -u

# 4. 手册清单 vs 目录
grep -A9 "REFERENCE_NAMES" packages/agent/src/prompts.ts
ls packages/agent/references

# 5. 文档里的旧符号
grep -rn "load_reference\|subagents.ts\|emit_case\|courseTools" docs/00-mvp README.md
```
