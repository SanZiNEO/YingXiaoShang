## 1. 要什么（学生可见结果）

学生说「帮我设计国潮联名调研」「我想做个消费者访谈」「这个作业要写研究设计」时，得到的是一页**能执行的研究设计**，不是一份可以直接交的成品：

- 先把「我想调研」还原成「要决定什么」，用一句话复述给学生确认。
- 只问**一个**真正卡住的关键信息；能不问就不问。
- 给六段结构：研究问题、目标、方法取舍、抽样、风险、下一步。
- 每个方法都要写「为什么选它、为什么不选另一个」。
- 每条风险配缓解动作；没有证据的判断集中列在「证据缺口」。
- 结尾只给**一个**本周能完成的动作。

学生要附件时产出 HTML 页面（`page`）；不要附件就在聊天里给骨架。**不直接给问卷终稿。**

## 3. 行为（一轮里怎么发生）

1. **复述决策**：「你要决定的是『联名款先上哪个品类』，对吗？」——学生否认就先改这一句，不往下走。
2. **找缺失**：列出 3–5 个未知项（目标人群、预算、时间窗、可触达样本、已有数据），挑出**一个**真正卡住的问。
3. **在假设下给结构**：明确写「假设你能触达 X，若假设不成立，抽样那一段要改」。
4. **做取舍**：在访谈 / 问卷 / 实验 / 二手数据 / 观察之间选，写清为什么不选另一个。
5. **标缺口**：把「目前没有证据支撑的判断」集中列出，不藏在正文。
6. **收束**：一个本周能完成的动作，不铺长待办。
7. **要不要附件**：学生要「一份」才 `write_page`；否则聊天里讲完。

## 4. 契约

### 4.1 页面骨架（`write_page` 的 `html`）

| 小节（`<h2>`） | 必须写清 | 常见错法（页面里不许出现） |
|---|---|---|
| 要支持的决策 | 一句话决策问题 + 不做什么 | 「全面了解消费者」 |
| 研究问题与假设 | 每条假设配「什么数据能支持或推翻」 | 把「了解」当研究问题 |
| 方法取舍 | 选了什么、为什么、为什么不选另一个 | 只列方法名 |
| 抽样 | 抽样框、样本量逻辑、招募渠道、时间成本 | 「发 100 份问卷」但说不清发给谁 |
| 风险与缓解 | 偏差、伦理、数据质量、外部效度；每条配动作 | 只写「注意样本量」 |
| 证据缺口 | 目前没有证据支撑的判断 | 把猜测写成结论 |
| 下一步 | 本周能完成的第一个动作 | 列 10 条待办 |

### 4.2 写作规则

- 指标保留英文缩写时首次出现加中文（如 CAC 获客成本）。
- 涉及数字：标来源与口径；没有来源写「待补数据」，不写伪精确的样本量。
- 研究设计不超过 1 页；不写问卷题目正文、不写访谈提纲全文。
- 页面里不出现内部 id、阶段标签、置信度。

### 4.3 「只问一个」的判据

一轮里最多一个问句用于补信息；其余未知项写进页面「证据缺口」，让学生自己补。已有信息能推断的（章节、人群、课程作业要求）不再问。

## 5. 边界（不做什么、失败怎么表现）

- **不代写成品**：不给可直接提交的完整方案、完整问卷、完整访谈提纲。
- **不虚构数据**：不编市场规模、增长率、竞品份额；需要时说清「这里需要一组真实数据，建议从哪类来源取」。
- **不跳步**：学生还没确认决策问题时，不直接给问卷或目录。
- **不堆框架**：不把 STP、4P、SWOT 全列一遍；用哪个说明为什么。
- **失败表现**：学生一句话给不出决策 → 复述两个候选让他选一个，而不是硬写；材料不足 → 页面里明写缺口，不拿套话补齐。

## 6. 验收（场景 → 期望）

1. **「帮我设计国潮联名调研」** → 先复述决策；只问一个缺的信息（如「你能触达哪个学校/商圈的人群」）；给出六段骨架页面，方法与抽样都带取舍。
2. **信息已足够**（学生已给人群、时间、预算）→ 不再追问，直接给骨架，并在页面里标「假设」。
3. **「直接给我一份问卷」** → 拒绝给终稿，给研究问题 + 方法取舍 + 问卷该覆盖的维度，说明为什么先定方法。
4. **「校园二手书调研怎么做」** → 页面含抽样框与招募渠道；没有真实样本量依据时写「待补数据」，不出现「发 200 份」这类无来源数字。
5. **只要口头建议**（「随口说说怎么调研」）→ 聊天里给 3–5 句骨架，右栏不新增产物。

## 8. MVP 范围与后续

**MVP 做到哪**

- 调研设计统一走「复述决策 → 只问一个 → 六段骨架 → `write_page`」。
- 方法取舍、风险配缓解、证据缺口、一个下一步，四项缺一不合格。
- 不给问卷终稿、不编数据；数字无来源写「待补数据」。

**后续**

- 补一份 `research-coach` skill（判据）：只问一个、方法必须带取舍、不跳步，做成可勾选的 6–8 项自查（[R04](R04-skills.md)）。
- 旧 `ResearchService` 退场：确认无人调用后删除服务、旧表写入与 `research_design` 渲染分支。

**明确不做**

- 不做七步流水线，不逐步 emit 结构化调研件。
- 不做问卷自动生成与投放。
- 不做财务/预算模型。
