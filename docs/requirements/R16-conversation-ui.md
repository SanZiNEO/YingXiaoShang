# R16 对话与三栏界面

> 状态：MVP（本轮）
> 依赖：[R15 产物与导出](R15-artifacts.md)、[R13 成长卡与能力评价](R13-growth-card.md)、[R14 学情与记忆](R14-profile-memory.md)、[R18 模型运行时](R18-model-runtime.md)、[R19 品牌与文案](R19-brand-copy.md)
> 代码：`apps/desktop/src/renderer/src/`、`apps/desktop/src/main/index.ts`
> 上位原则：[`../principles/single-agent.md`](../principles/single-agent.md)

## 1. 要什么（学生可见结果）

- **左栏**：新对话、最近对话、学习档案、设置。会话按更新时间排列，显示章节与状态。
- **中栏**：唯一的对话主线。诊断、讲解、追问、出题、复盘都在这里发生；没有第二个入口，也没有角色切换。
- **右栏**：当前任务的工作区。标签页可多开、可关闭、可全屏；产物在这里打开，依据在这里核对。
- 学生不用先选章节，也不用选「用谁」。章节由对话与状态推断，不确定时只问一句；需要时可在标题栏手动调整。
- 右栏五类标签固定为：**任务概览、产物、依据、过程 / 记录、文件**。依据显示知识点、新闻、教材的中文名，不显示 `kp_*`。
- 学生看不到内部枚举、置信度、工具名、步骤、分工名、原始报错、裸 JSON、Markdown 标记。
- 没配模型 Key 时，界面给一句人话，不吐英文堆栈。

## 2. 落位（提示词 / 工具 / skill / 数据）

| 层 | 职责 |
|---|---|
| 界面 | `App.tsx` 三栏骨架与会话；`workspace.tsx` 右栏标签与内容；`ui.tsx` 沙箱与基础组件；`renderers.tsx` 产物分派；`labels.ts` 中文标签 |
| 数据 | `DocTab`（标签）、`Artifact`（产物）、`Citation`（依据）、`LearningStateSnapshot`（状态）、`TurnRow`（轮次） |
| 提示词 | 回复说人话、不暴露内部；只在学生明确要附件时产页面；不把附件正文抄回聊天 |
| 工具 | 不新增界面工具。`write_page` / `emit_question_set` 的结果由界面接住 |
| 主进程 | `learning:chat`、`learning:invoke`、`learning:answer`、`learning:answer-set`、`learning:settings:*`；窗口标题「营小商」 |

- 界面不判断学生意图，不按关键词切页面；显示什么由本轮结果与标签决定。
- 不新增第二个说话人、角色路由或功能入口首页。

## 3. 行为（一轮里怎么发生）

1. 打开软件：左栏列出最近对话；中栏显示空状态（一句话 + 三个建议）；右栏不占位，有标签时才出现。
2. 学生输入并回车：中栏立即出现自己的消息；进度条用中文动作（「正在读知识点定义」「正在取教材材料」），不显示工具名。
3. 模型流式输出：文字逐段出现；一轮结束前不显示内部阶段、意图、置信度。
4. 本轮有产物：题目集或页面自动在右栏打开；只有引用没有产物时打开「依据」；两者都没有就不开右栏。
5. 右栏标签可切换、关闭、全屏；产物可导出（页面导出 HTML 原件，题目集导出 Markdown/Word），可打开所在文件夹。
6. 出错：`friendlyError` 把英文错误换成一句中文，显示在输入框上方；不弹堆栈、不写内部方法名。
7. 设置：填写或清除本机 Key，说明环境变量优先；保存后下一轮生效。

## 4. 契约（工具签名、数据结构、字段、命令）

**三栏宽度**（`layout/columns.ts`）：

| 项 | 规则 |
|---|---|
| 左栏 | 200–320px，默认 240px；视口小于 900px 自动收起 |
| 中栏 | 最小 480px，占用剩余空间 |
| 右栏 | 最小 360px，最大为视口 62%，默认 42%；空间不足时先收起右栏 |

**标签类型**（`DocKind` → 中文名）：

| kind | 标签 |
|---|---|
| `overview` | 任务概览 |
| `artifacts` | 产物 |
| `evidence` | 依据 |
| `process` | 过程 / 记录 |
| `files` | 文件 |
| `artifact` | 产物标题（如「成长卡」「题目集 · 3 题」） |
| `file` / `news` / `source` | 文件名、新闻标题、教材出处 |

**空状态文案**：

| 位置 | 文案要求 |
|---|---|
| 中栏无消息 | 一句话说明可以直接说，章节由营小商判断；给 3 个可点建议 |
| 右栏无标签 | 说明这里只放本次任务的工作文档，点 + 打开 |
| 产物列表为空 | 「还没有产物。让营小商出题、做调研或写 BP。」 |
| 文件列表为空 | 「还没有导出文件。」 |
| 依据为空 | 「本轮没有引用。」并说明解释类问题会列出知识点与原文 |

**错误文案**（主进程统一映射）：

| 情况 | 学生看到 |
|---|---|
| 未配置 Key | 还没配置模型密钥：点左下角「设置」填入 DeepSeek Key 后再发一次 |
| Key 无效/过期 | 模型密钥无效或已过期，请在「设置」里重新填写 |
| 限流 | 模型调用太频繁了，等几秒再发一次 |
| 超时/断连 | 模型响应超时，这一段没有记成你的作答，可以直接重发 |
| 其他 | 允许中文说明；不得出现 `Error invoking remote method`、堆栈或内部方法名 |

**不可见清单**：`phase`、`intent`、`decision`、`confidence`、`routing`、`steps`、`seq`、`attempts`、工具名、类名、分工名、原始 `last_error`。

**HTML 沙箱**：`HtmlFrame` 用 `sandbox=""` + CSP `default-src 'none'; style-src 'unsafe-inline'; img-src data:; font-src data:`；页面不能执行脚本、不能同源、不能引外链。

## 5. 边界（不做什么、失败怎么表现）

- 不做角色或分工选择器；不做「先选章节」的引导页；不做功能入口集合。
- 不把内部枚举、路由策略、工具调用日志、步骤 read/write、分工名放进界面。
- 不直接显示 Markdown 标记或裸 JSON：聊天用 Markdown 渲染，产物用 HTML 或结构化卡片。
- 右栏不是阅读器：默认在聊天里讲完；只有学生明确要附件时才开新标签。
- 不做小程序、不做 Web 端；多窗口不在本轮。
- 失败表现：页面为空 → 「这份产物暂时没有可展示的内容」；文件类型不支持 → 说明可打开所在文件夹；引用定位失败 → 「原文无法定位，旧引用需复核」并打开依据列表；右栏空间不足 → 自动收起，不挤压中栏到不可读。

## 6. 验收（场景 → 期望）

| # | 场景 | 期望 |
|---|---|---|
| 1 | 首次打开 | 左栏有新对话、最近对话、学习档案、设置；中栏空状态一句话 + 建议；**没有**角色选择器，也不要求先选章节 |
| 2 | 「直播间为什么让人冲动消费」 | 中栏一段解释 + 检查问题；右栏「依据」显示「知识点 · 消费者动机」等中文名，不出现 `kp_*`；无 `##`、无裸 JSON |
| 3 | 「给我一张成长卡」 | 右栏打开页面标签，HTML 在沙箱渲染；可全屏、可关闭、可导出 `.html`；聊天只给摘要，不贴整份卡片 |
| 4 | 未配置 Key 时发消息 | 显示「还没配置模型密钥：点左下角「设置」…」；不出现 `DEEPSEEK_API_KEY`、英文堆栈、内部方法名 |
| 5 | 打开「过程」标签 | 只显示整理水位与轮次的中文状态；不出现路由策略、分工名、`seq`、`attempts`、原始错误 |
| 6 | 窗口缩到 900px 以下 | 左栏自动收起；右栏可全屏；320px 宽的页面不横向滚动 |

## 8. MVP 范围与后续

**MVP 做到哪**：三栏骨架与折叠；单主线；五类右栏标签；产物打开、关闭、全屏、导出；依据中文名；空状态；设置；统一中文错误；HTML 沙箱；聊天不显示内部状态与裸 JSON。

**后续留什么**：会话搜索与重命名；标签拖拽、固定与恢复；多窗口；深色模式；键盘快捷键与无障碍；右栏「本轮读过什么」的可展开清单；过程页按轮次回放。

**明确不做**：角色或分工选择器；章节必选引导；功能入口首页；内部日志/调试面板；在聊天或产物里显示 Markdown 标记、裸 JSON、工具名、类名；小程序与 Web 端。
