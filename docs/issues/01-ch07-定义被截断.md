## 影响

对应需求分层里的 **A2（分析必须挂在知识点上）** 与 **A3（讲到机制层）**：

- 做 STPB 分析时，AI 讲得出 S（细分）和 P（定位）的边界，**讲不出 T 该选哪种战略**；
- 定位只能复述"里斯和特劳特"，讲不出避强 / 对抗；
- 品牌只能讲"要不要品牌化"，讲不出品牌名称 / 延伸 / 再定位。

→ 结果就是"定义 + 案例复述"，这正是老师说的「感觉乖乖的但是说不出来」。
