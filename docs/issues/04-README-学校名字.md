## 现象

`README.md` 第 3 行：

```
**山东大学威海商学院市场营销专业 · 营小商**
```

## 依据

`docs/00-mvp/营小商-MVP-需求分层-v0.1.md` 的硬约束：

> **X4｜不出现学校名字** —— 校验方式：全局搜校名关键词，命中即不合格
> **X3｜名字：营小商 / 营小商伴学智能体；副标题「市场营销伴学」**

老师原话（10-20 9:52）：

> 「能否把山东大学威海 市场营销这行字改为 市场营销伴学？」
> 「**不要出现学校的名字**」

## 影响

README 是仓库对外第一屏。老师若在提交材料里引用仓库链接，这一行直接违反他自己提的约束。

`apps/desktop` 界面那行已经删掉了（见 `docs/90-archive/00-mvp-v1/营小商-需求整理-2026-10-20.md`），只剩 README。

## 改法

```diff
-**山东大学威海商学院市场营销专业 · 营小商**
+**营小商 · 市场营销伴学**
```

`docs/90-archive/**` 下的历史文档属于归档，可以不改（或整体保留原样以示留痕）。

- [ ] `grep -ri "山东大学\|威海\|山威" README.md apps/ docs/00-mvp docs/10-long-term docs/20-features` 无命中
