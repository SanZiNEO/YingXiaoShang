用营销战略的知识，分析一下安踏这条新闻
案例精讲 · 5 个知识点
这条新闻的主线不是“卖得好不好”，而是安踏从多品牌覆盖退回主品牌：
① 它长期用主品牌、FILA、始祖鸟、迪桑特覆盖不同价格带，这是差异化营销；
② 现在喊“单品牌超越耐克中国”，是把资源往一块收；
③ 而每个并购品牌又被自己的定位关住了——迪桑特“被小众高端的定位局限”。
顺序看：S 细分 → T 目标 → P 定位 → B 品牌。右侧已生成完整讲解。
FILA 关店那部分，算品牌延伸失败吗
追问 · 品牌战略的类型
算，但要分清主体：FILA KIDS、FILA FUSION 是延伸（借 FILA 的名进童装与潮流）， 主品牌重塑才是再定位。
原文给的理由很具体——儿童市场饱和（外部）+ 差异化不足（内部）。差异化不足的意思是： 借了名，却没给出新的购买理由。

依据 · 《安踏步入规模新高下半场：发力聚焦主品牌为何重要？》　华尔街见闻　2025-03-24
原文链接：wallstreetcn.com/articles/3743764　｜　引文均可回原文核对
01目标市场选择战略 STP · T定义先行
定义企业评估细分市场、决定为哪些购买者群体服务，并选择覆盖方式的战略。覆盖方式有无差异营销、差异化营销、集中化营销三种。
判断线索出现“多品牌覆盖 / 聚焦主品牌 / 一套打全场”这类表述时，就该往这三种方式上对。
案例对应主品牌＋FILA＋始祖鸟＋迪桑特覆盖不同价格带 → 差异化营销；喊“单品牌超越耐克中国” → 资源回收，向集中化倾斜；超级安踏全品类全年龄段 → 主品牌内部的一次无差异营销。
“2025年初，安踏CEO徐阳喊出‘3年内单品牌超越耐克中国’的口号。”
02市场定位的含义与价值 STP · P定义先行
定义为产品塑造特色、树立与众不同的市场形象，以求在顾客心目中形成特殊偏好，并在细分市场占据强有力的竞争地位。
判断线索看有没有一个能被顾客用一句话记住的心智标签，以及这个标签带来的溢价或天花板。
案例对应FILA 的中高端定位带来近 70% 毛利率；迪桑特、可隆则“被小众高端的定位局限”——同一条定位，既给溢价，也设天花板。
“行业格局上，FILA正面临中高端竞争加剧、潮流市场增长疲软的双重危机。”
03市场定位的方式 STP · P定义先行
定义建立差异的具体打法：领导者定位、创新式定位、反定位；避强定位、对抗定位；初次定位与重新定位。
判断线索问两件事：是抢同一个位置，还是另立一个位置；是第一次进入，还是调整旧位置。
案例对应主品牌扎在大众市场与下沉渠道 → 避强定位（不进耐克阿迪主战场）；把品牌“切得更小”、按渠道差异化 → 重新定位。
“徐阳的解法是将安踏品牌切得‘更小’，在不同渠道执行差异化策略，”
04品牌战略的类型 STP · B定义先行
定义品牌化战略、品牌名称战略、品牌延伸战略、品牌再定位战略四类。
案例对应FILA KIDS、FILA FUSION 属品牌延伸（借名进童装与潮流）；主品牌重塑属品牌再定位；安踏 / FILA / 始祖鸟并存属企业名与个别品牌并用。
“2024年上半年，FILA FUSION净关闭了约10%的门店。”
